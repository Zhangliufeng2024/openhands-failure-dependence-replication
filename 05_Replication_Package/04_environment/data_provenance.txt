===================== ROW-ORDER CAVEAT =====================

Rows are NOT ordered by attempt. trajectory_id is an opaque hash with no
timestamp, so repeated attempts at one task are not adjacent in the file
(example: PlasmaFAIR__sdf-xarray-24 at rows 0 and 2,398). Attempt ORDER is
therefore unrecoverable from the released file.

Consequences:
  - CCRM's ε₁/ε₀ = 7.1× is not computable (it conditions on the
    first attempt having failed).
  - Any transition rate keyed on "the previous attempt" is meaningless. Computed
    naively on row order it yields a ratio of 0.111, an apparent nine-fold
    cascade that is entirely artifactual.
